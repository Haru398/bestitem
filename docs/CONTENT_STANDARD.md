# item.monster 콘텐츠 기준

## 글의 목적

한 글은 한 가지 검색 질문에 답해야 합니다. 목표는 상품을 칭찬하는 것이 아니라 독자가 다음 세 가지를 판단하도록 돕는 것입니다.

1. 이 제품이 내 사용 환경에 맞는가?
2. 판매 자료에서 사실로 확인되는 것은 무엇인가?
3. 결제 전에 추가로 확인해야 할 위험이나 누락 정보는 무엇인가?

## 작성 전 준비

- 대표 검색어 한 개와 검색 의도를 정합니다.
- 판매 상세 페이지와 제공 이미지를 확인합니다.
- 확인된 사양과 확인되지 않은 사양을 별도로 적습니다.
- 직접 사용, 실측, 제조사 자료, 판매자 설명을 서로 구분합니다.
- 가격과 옵션은 바뀌므로 고정 가격이나 ‘최저가’라고 쓰지 않습니다.

## 필수 구성

- 제목: 제품명이 아니라 사용자의 질문과 판단 기준이 드러나야 합니다.
- 설명: 55~170자, 페이지에서 얻을 판단을 요약합니다.
- 도입: 180자 이상, 문제와 글의 검증 범위를 밝힙니다.
- 구매 판단: 적합한 사람, 맞지 않는 사람, 결제 전 확인사항을 각각 제시합니다.
- 본문: 4개 이상의 섹션, 섹션마다 180자 이상입니다.
- 결론: 140자 이상, 장점과 한계를 함께 요약합니다.
- 이미지 설명: 파일명이나 ‘이미지1’ 대신 보이는 기능을 설명합니다.
- 근거: 확인한 자료와 확인하지 못한 항목을 구체적으로 적습니다.
- FAQ: 사용자가 결제 직전에 묻는 질문에 짧고 직접적으로 답합니다.

검수 완료 글은 전체 본문 2,200자 이상이어야 합니다. 길이를 채우기 위한 반복 문장보다 비교 기준, 설치 조건, 안전, 호환성, 반품 조건을 보강합니다.

## 쓰지 않는 표현

- 직접 사용하지 않았는데 ‘실사용 후기’, ‘써보니’라고 쓰는 표현
- 근거 없는 ‘완벽’, ‘필수템’, ‘끝판왕’, ‘사각지대 제로’, ‘무조건 추천’
- 확인하지 않은 ‘대용량’, ‘강력’, ‘오래가는’, ‘안전한’, ‘최저가’
- 의학적 근거 없는 치료, 예방, 통증 완화, 혈당·당뇨 관련 표현
- 경쟁 제품과 조건을 맞추지 않은 일방적인 우위 주장

## 사람 냄새 나는 문장 기준

사이트의 목소리는 ‘편집팀 보고서’가 아니라 운영자 한 명이 대신 찾아보고 알려주는 구매 메모에 가깝게 씁니다.

- 첫 문장은 검색자가 실제로 겪는 장면이나 망설임에서 시작합니다.
- 모든 글을 `이 글은 직접 사용한 후기가 아닙니다`로 시작하지 않습니다. 사용 여부는 문맥 속에서 한 번만 자연스럽게 밝힙니다.
- 짧은 문장과 긴 문장을 섞고, 같은 종결어미를 세 번 이상 이어 쓰지 않습니다.
- `정리했습니다`, `확인합니다`, `제시합니다` 같은 보고서 표현을 한 문단에서 반복하지 않습니다.
- 운영자의 판단은 말할 수 있지만 직접 쓰지 않은 제품을 `제가 써보니`, `체감상`이라고 꾸미지 않습니다.
- 소제목은 사양 이름만 적기보다 독자가 궁금해할 질문이나 결론이 드러나게 씁니다.
- 완성한 글은 소리 내어 읽어보고, 평소 대화에서 쓰지 않을 문장은 다시 고칩니다.

## 사실을 표현하는 방법

나쁜 예: `395nm 유도등이 모기를 효과적으로 모두 잡아줍니다.`

좋은 예: `판매 이미지에는 395nm 유도등이 표시되어 있습니다. 실제 유인 결과는 주변 밝기와 설치 위치에 따라 달라질 수 있습니다.`

나쁜 예: `1800mAh 대용량 배터리라 밤새 사용할 수 있습니다.`

좋은 예: `배터리 표기는 1800mAh입니다. 모드별 사용 시간과 충전 중 작동 여부는 판매자에게 별도 확인해야 합니다.`

## 공개 판정

- `draft`: 새 글의 작업 초안이며 미리보기만 가능하고 검색에는 노출하지 않음
- `reviewed`: 위 기준과 자동 검사를 통과한 글
- `legacy`: 이전 글을 보존한 상태이며 순차 검수 대상
- `hidden`: 공개하면 안 되는 초안 또는 폐기 대상
- `indexable: false`: 페이지는 남기되 검색엔진의 색인 대상에서는 제외

`npm run content:validate`가 실패하면 배포하지 않습니다. 자동 검사는 최소 기준일 뿐이며, 사람이 제목·근거·과장 여부를 마지막으로 읽어야 합니다.

## PC 전문가이드 기준

전문가이드는 상품명을 바꿔 끼우는 글이 아니라 한 가지 긴 검색 질문을 해결하는 자료입니다. 예: `라이젠 7500F 메인보드 고르는 법`, `RTX 5060 파워 용량과 보조전원 확인`, `M.2 슬롯 사용 시 SATA 포트가 꺼지는지 확인하는 법`.

- CPU·GPU·메인보드·메모리 제조사의 공식 사양과 해당 완제품 제조사의 지원 문서를 우선합니다.
- 칩셋 일반 사양과 특정 메인보드의 실제 포트·BIOS를 구분합니다.
- 공식 출처를 3개 이상 기록하고 각 출처의 확인 날짜를 저장합니다.
- 실측하지 않은 온도, 프레임, 소음과 전력 수치를 쓰지 않습니다.
- 글의 결론은 ‘추천 제품’보다 사용자가 공식 지원표에서 다시 확인할 순서를 먼저 제공합니다.
- `npm run guide:new -- --slug guide-example --title "제목" --query "대표 검색어"`로 noindex 초안을 만들 수 있습니다.

## 제조사 이미지와 미디어 에셋

제조사 제품 페이지에 보이는 사진이라고 해서 자동으로 상업적 재게시가 허용되는 것은 아닙니다. 흔히 `공식 제품 렌더`, `프레스 이미지`, `미디어 에셋`, `미디어 키트`라고 부르며 아래 조건을 지킵니다.

1. 제조사 미디어 라이브러리나 파트너 자료실처럼 다운로드 목적과 이용 조건이 명시된 원본만 사용합니다.
2. `media`에 로컬 경로, 대체 텍스트, 제작자, 원본 URL, 라이선스·이용 조건 URL을 기록합니다.
3. 허용 범위가 불명확하면 이미지를 복제하지 않고 공식 페이지로 연결하거나 자체 제작 도식을 사용합니다.
4. 제조사 이미지를 편집·합성해 공식 인증이나 후원처럼 보이게 만들지 않습니다.
5. 쿠팡에서 제공받은 제휴용 이미지는 `authorized-affiliate`, 제조사 이용 조건을 확인한 이미지는 `licensed-manufacturer`, 직접 만든 도식은 `original`로 구분합니다.

검수 완료된 PC 전문 글은 시각 자료를 보통 5~7장 사용합니다. 최소 기준은 **실제 제품 사진 4장과 자체 설명 도식 1장**입니다. 첫 화면에 사진을 몰아넣지 않고 본문 소제목 사이에 나눠 배치하며, 연속된 텍스트가 2~3문단을 넘기기 전에 관련 사진이나 도식이 나오게 구성합니다. 사진 아래 캡션에는 사진에서 확인할 부품·포트·모델 차이를 한 문장으로 설명합니다. 실제 제품 사진은 제조사 미디어킷에서 재사용이 허용된 자료 또는 쿠팡 파트너스가 광고 제작용으로 제공한 정확한 상품 이미지만 인정합니다. 같은 제품군의 비슷한 모델을 대신 넣지 않으며, 무선·비무선, 리비전, 색상처럼 헷갈리기 쉬운 차이는 캡션에 적습니다.

검수 완료된 PC 가이드는 출처 기록이 3개 미만이거나 외부 이미지의 원본·이용 근거가 빠지면 자동 검사를 통과하지 못합니다.
