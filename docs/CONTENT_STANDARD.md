# item.monster 콘텐츠 기준

## 글의 목적

한 글은 한 가지 검색 질문에 답해야 합니다. 목표는 상품을 칭찬하는 것이 아니라 독자가 다음 세 가지를 판단하도록 돕는 것입니다.

1. 이 제품이 내 사용 환경에 맞는가?
2. 판매 자료에서 사실로 확인되는 것은 무엇인가?
3. 결제 전에 추가로 확인해야 할 위험이나 누락 정보는 무엇인가?

## 작성 전 준비

- 대표 검색어 한 개와 검색 의도를 정합니다.
- 판매 상세 페이지와 제공 이미지를 확인합니다.
- 확인된 사양과 확인되지 않은 사양을 별도로 적습니다.
- 직접 사용, 실측, 제조사 자료, 판매자 설명을 서로 구분합니다.
- 가격과 옵션은 바뀌므로 고정 가격이나 ‘최저가’라고 쓰지 않습니다.

## 필수 구성

- 제목: 제품명이 아니라 사용자의 질문과 판단 기준이 드러나야 합니다.
- 설명: 55~170자, 페이지에서 얻을 판단을 요약합니다.
- 도입: 180자 이상, 문제와 글의 검증 범위를 밝힙니다.
- 구매 판단: 적합한 사람, 맞지 않는 사람, 결제 전 확인사항을 각각 제시합니다.
- 본문: 4개 이상의 섹션, 섹션마다 180자 이상입니다.
- 결론: 140자 이상, 장점과 한계를 함께 요약합니다.
- 이미지 설명: 파일명이나 ‘이미지1’ 대신 보이는 기능을 설명합니다.
- 근거: 확인한 자료와 확인하지 못한 항목을 구체적으로 적습니다.
- FAQ: 사용자가 결제 직전에 묻는 질문에 짧고 직접적으로 답합니다.

검수 완료 글은 전체 본문 2,200자 이상이어야 합니다. 길이를 채우기 위한 반복 문장보다 비교 기준, 설치 조건, 안전, 호환성, 반품 조건을 보강합니다.

## 쓰지 않는 표현

- 직접 사용하지 않았는데 ‘실사용 후기’, ‘써보니’라고 쓰는 표현
- 근거 없는 ‘완벽’, ‘필수템’, ‘끝판왕’, ‘사각지대 제로’, ‘무조건 추천’
- 확인하지 않은 ‘대용량’, ‘강력’, ‘오래가는’, ‘안전한’, ‘최저가’
- 의학적 근거 없는 치료, 예방, 통증 완화, 혈당·당뇨 관련 표현
- 경쟁 제품과 조건을 맞추지 않은 일방적인 우위 주장

## 사실을 표현하는 방법

나쁜 예: `395nm 유도등이 모기를 효과적으로 모두 잡아줍니다.`

좋은 예: `판매 이미지에는 395nm 유도등이 표시되어 있습니다. 실제 유인 결과는 주변 밝기와 설치 위치에 따라 달라질 수 있습니다.`

나쁜 예: `1800mAh 대용량 배터리라 밤새 사용할 수 있습니다.`

좋은 예: `배터리 표기는 1800mAh입니다. 모드별 사용 시간과 충전 중 작동 여부는 판매자에게 별도 확인해야 합니다.`

## 공개 판정

- `reviewed`: 위 기준과 자동 검사를 통과한 글
- `legacy`: 이전 글을 보존한 상태이며 순차 검수 대상
- `hidden`: 공개하면 안 되는 초안 또는 폐기 대상
- `indexable: false`: 페이지는 남기되 검색엔진의 색인 대상에서는 제외

`npm run content:validate`가 실패하면 배포하지 않습니다. 자동 검사는 최소 기준일 뿐이며, 사람이 제목·근거·과장 여부를 마지막으로 읽어야 합니다.
