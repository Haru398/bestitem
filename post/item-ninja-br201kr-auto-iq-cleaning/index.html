Auto-iQ Crush와 수동 버튼은 같은 용도가 아닙니다

입력 상세 원본에는 CRUSH 버튼을 한 번 누르면 블렌딩과 일시 정지 패턴을 결합한 뒤 자동으로 멈춘다고 표시됩니다. SharkNinja의 BR201KR 퀵 가이드도 Crush를 Auto-iQ 프로그램으로, Low·Med·High·Pulse를 별도의 수동 조작으로 구분합니다. 따라서 버튼 수가 많다는 이유만으로 모든 재료에 같은 결과를 기대하기보다, 자동 프로그램이 필요한지와 직접 속도를 바꿔야 하는지를 먼저 정하는 편이 좋습니다. 수동 버튼을 쓸 때는 공식 안내처럼 한 번의 연속 작동 시간을 길게 잡지 않고, 재료 상태를 확인하며 멈춰야 합니다. 제휴 링크를 열었을 때에도 BR201KR 모델명과 동일한 버튼 구성이 보이는지 결제 직전에 다시 확인하세요.

2.1L 피처와 3단 블레이드는 준비량·세척 순서와 함께 보세요

제조사 제품 정보와 입력 원본은 BR201KR에 2.1L 피처와 3단 블레이드를 안내합니다. 2.1L는 재료를 담는 피처의 표기이지, 어떤 재료든 한 번에 같은 양을 처리한다는 뜻은 아닙니다. 얼음, 과일, 수분이 적은 재료처럼 조합이 달라지면 넣는 순서와 양, 작동 횟수를 공식 안내에 맞춰 조절해야 합니다. 특히 블레이드는 분리되는 날카로운 부품입니다. 사용설명서는 피처에서 블레이드를 꺼내거나 세척할 때 주의하고, 전원을 뽑은 뒤 분리하도록 안내합니다. 피처 용량이 평소 사용량에 맞는지뿐 아니라, 사용 뒤 블레이드를 안전하게 다룰 수 있는 주방 동선인지도 구매 전 확인 항목에 넣으세요.

Low·Med·High·Pulse는 수동 확인이 필요한 조작입니다

원본의 조작부는 Low, Med, High, Pulse를 별도의 수동 버튼으로 보여 줍니다. 공식 퀵 가이드에서는 수동 모드의 연속 작동 시간을 60초 이내로 안내하므로, 긴 시간 동안 계속 돌려 두는 기능으로 받아들이기보다 중간에 피처 안의 상태를 확인하는 조작으로 보는 편이 안전합니다. Pulse는 짧게 끊어 동작시키는 버튼이므로, 재료가 멈춘 상태에서 뚜껑과 피처가 제대로 잠겼는지 먼저 확인해야 합니다. 스무디·살사·딥소스처럼 상세 이미지에 예시로 나온 음식도 재료 비율과 양에 따라 필요한 시간과 결과가 달라집니다. 따라서 메뉴 이름만 보고 작동 시간을 정하지 말고, 공식 사용설명서의 재료 투입·뚜껑 결합·작동 순서를 우선하세요.
