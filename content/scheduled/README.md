# 시간당 공개 예약 큐

- `posts/`와 `images/`에는 아직 공개하지 않은 원고와 API 이미지가 들어 있습니다.
- 예약 원고에는 `publishedAt`·`updatedAt`을 미리 기록하지 않습니다.
- `.github/workflows/hourly-publish.yml`이 한국시간 매시 정각에 원고 한 건만 공개하고, 실행 시각을 실제 공개 시각으로 기록합니다.
- 공개 전에는 전체 예약 큐 검증과 원고 유사도 검사를, 공개 후에는 공개 콘텐츠 검증·정적 빌드·사이트맵 검증을 통과해야 배포합니다.
- 마지막 원고가 공개되면 시간당 워크플로를 자동으로 비활성화합니다.
- 쿠팡 파트너스 키는 로컬 후보 수집에만 사용하며 이 폴더나 GitHub Actions에는 저장하지 않습니다.

새 큐를 만들 때는 후보 목록을 검수한 뒤 `npm run schedule:prepare`와 `npm run schedule:validate`를 차례로 실행합니다. 기존 큐가 남아 있으면 기본적으로 중단하며, 검토 후 의도적으로 교체할 때만 `--replace`를 사용합니다.
